# Customer Behavior Analysis Dashboard (Excel Project)

# 🔷 Project Overview

This project presents an interactive Customer Behavior Analysis Dashboard built in Excel to analyze sales trends, customer demographics, and channel performance for an e-commerce business.

The goal is to transform raw transactional data into actionable business insights for decision-making.

# 🔷 Tools & Skills Used

Microsoft Excel

Pivot Tables & Pivot Charts

Slicers (Interactive Filters)

Data Cleaning (TRIM, IF, IFERROR)

Basic KPI Calculations
